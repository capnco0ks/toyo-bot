# 🛢 Telegram-бот оптового заказа моторных масел TOYO

Профессиональный Telegram-бот для оптовых продаж моторных и трансмиссионных масел. Позволяет клиентам просматривать структурированный каталог продукции, выбирать фасовки (канистры 1л/4л/5л/20л, бочки 208л), управлять корзиной, рассчитывать итоговую стоимость в тенге (₸) и оформлять оптовые заказы с автоматической отправкой в закрытый Telegram-чат менеджеров.

## ✨ Возможности системы

### 👤 Для клиентов:
- **🛢 Каталог товаров:** Удобный просмотр по категориям («Моторные масла», «Трансмиссионные масла») с пагинацией.
- **🔍 Поиск:** Моментальный поиск по вязкости (`5W-30`, `10W-40`, `0W-20`), артикулу, типу тары или названию.
- **📦 Карточка товара:** Полная спецификация — вязкость, литраж, тип упаковки (металл / пластик / бочка), цена в ₸.
- **🔢 Выбор количества:** Интерактивные кнопки `[-]` / `[+]`, а также ручной ввод любого оптового количества.
- **🛒 Умная корзина:** Подсчёт позиций, общего литража/штук и итоговой суммы, возможность изменять количество или удалять отдельные позиции.
- **✅ Быстрое оформление:** Формирование заказа и фиксация цены на момент покупки (**цена в заказе замораживается навсегда**).
- **📦 Мои заказы:** История всех предыдущих заказов с детальным составом и статусами.
- **📞 Связь с менеджером:** Прямой переход в диалог с отделом продаж.

### 👥 Для менеджеров (в Telegram-группе):
- Мгновенное получение карточки заказа с полным составом, суммой и кликабельным контактом клиента.
- Интерактивные кнопки: **`[ ✅ Принять ]`** и **`[ ❌ Отклонить ]`**.
- После принятия — кнопка **`[ 🏁 Отметить завершённым ]`**.
- Сообщение в группе автоматически обновляется, фиксируя имя менеджера и время обработки.
- Клиент получает уведомление об изменении статуса своего заказа.

### ⚙️ Для администраторов:
- Авторизация только по списку `ADMIN_IDS`.
- **💰 Изменение цен:** Выбор товара и ввод новой цены прямо в Telegram. Новая цена применяется для будущих заказов, старые заказы сохраняют историческую цену.
- **➕ Добавление товаров:** Пошаговый FSM-мастер для добавления новых масел.
- **🔄 Включение/Отключение:** Скрытие товара из каталога без удаления истории заказов.
- **📊 Статистика:** Сводка по обороту, количеству заказов, клиентам и активным товарам.

## 🚀 Пошаговая установка на Windows

Откройте **PowerShell** или **Windows Terminal** и выполните по порядку:

### 1. Перейдите в папку проекта
```powershell
cd C:\Users\User\Desktop\Toyo-bot
```

### 2. Создайте виртуальное окружение Python
```powershell
python -m venv .venv
```

### 3. Активируйте виртуальное окружение
```powershell
.venv\Scripts\activate
```
*(После активации в начале строки появится префикс `(.venv)`)*

### 4. Обновите pip и установите зависимости
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 🤖 Создание и настройка Telegram-бота в BotFather

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота (например, `TOYO Oil Wholesale Bot`).
4. Введите юзернейм бота, оканчивающийся на `bot` (например, `toyo_oil_order_bot`).
5. **Скопируйте полученный API токен** (например: `7123456789:AAFn892jklmsdf...`).
6. *(Рекомендуется)* Отключите Group Privacy для корректного чтения команд в группах:
   - Отправьте `/setprivacy` -> Выберите вашего бота -> Нажмите `Disable`.

## 👥 Настройка группы менеджеров (ORDER_CHAT_ID)

1. Создайте в Telegram группу (например: `TOYO | Оптовые заказы`).
2. Добавьте созданного бота в эту группу как **Администратора**.
3. Назначьте боту права:
   - ✅ Отправка сообщений (*Send Messages*)
   - ✅ Закрепление сообщений (*Pin Messages*)
4. Чтобы узнать **ID группы**:
   - Добавьте в группу бота [@raw_data_bot](https://t.me/raw_data_bot) или [@getidsbot](https://t.me/getidsbot).
   - Бот пришлёт JSON-ответ. Найдите поле `chat` -> `id` (он начинается с `-100...`, например `-1002345678901`).
   - Удалите сервисного бота из группы.

## 🔑 Конфигурация переменных окружения (.env)

Создайте или отредактируйте файл `.env` в корневой папке `Toyo-bot/`:

```env
# Токен бота, полученный от @BotFather
BOT_TOKEN=7123456789:AAFn892jklmsdf...

# Telegram ID администраторов через запятую (узнать свой ID можно в @userinfobot)
ADMIN_IDS=123456789,987654321

# ID группы менеджеров для приёма заказов (со знаком минус и префиксом -100)
ORDER_CHAT_ID=-1002345678901

# Юзернейм менеджера по оптовым продажам (без символа @)
MANAGER_USERNAME=toyo_sales_manager

# Путь к базе данных SQLite
DATABASE_URL=sqlite+aiosqlite:///data/database.db

# Путь к исходному Excel-файлу с прайс-листом
DEFAULT_PRICE_PATH=C:/Users/User/Desktop/ПРАЙС TOYO 01.09.2026.xls
```

## 📥 Импорт товаров и цен из Excel (.xls)

В проект встроен автоматический парсер, который распознаёт категории («Моторные масла» / «Трансмиссионные масла»), литраж канистр и бочек (1л, 4л, 5л, 20л, 208л), тип тары (металл / пластик), вязкость и оптовые цены.

Для запуска импорта выполните:

```powershell
python scripts/import_products.py
```

Или укажите путь к другому файлу прайса:
```powershell
python scripts/import_products.py "C:\Путь\К\Вашему_Прайсу.xls"
```

> [!TIP]
> Скрипт защищен от дублирования: при повторном запуске он не создаст дубликаты, а лишь обновит цены и характеристики, если они изменились в таблице.

## 📖 Руководство пользователя

1. Нажмите `/start` в боте.
2. Откройте **🛢 Каталог** и выберите категорию (например, *Моторные масла*).
3. Выберите нужную позицию (например, *TOYO 5W30 4 л Металл*).
4. Кнопками `[-]` и `[+]` или кнопкой `🔢` задайте количество и нажмите **🛒 Добавить в корзину**.
5. Добавьте другие позиции при необходимости.
6. Перейдите в **🛒 Корзина** — бот покажет состав, количество и общую сумму в тенге (₸).
7. Нажмите **✅ Оформить заказ** и подтвердите отправку.
8. Заказ мгновенно поступит в группу менеджеров с кнопками принятия в работу!

## ⚙️ Панель администратора

Для пользователей, чей Telegram ID указан в `ADMIN_IDS`, в главном меню доступна кнопка **`⚙️ Админ-панель`** (или команда `/admin`):

1. **💰 Изменить цену:** Выберите категорию -> товар -> введите новую цену. Цена мгновенно обновится для новых заказов, а история предыдущих заказов останется нетронутой.
2. **➕ Добавить товар:** Интерактивный диалог для ввода названия, литража, тары, вязкости и цены.
3. **🔄 Вкл / Выкл товар:** Возможность временно скрыть товар из каталога (он не будет отображаться клиентам, но история старых заказов с ним не сломается).
4. **📊 Статистика:** Мгновенный отчёт по заказам, общему обороту и количеству пользователей.

## 💾 Резервное копирование и обслуживание БД

База данных хранится в локальном файле:
`Toyo-bot\data\database.db`

### Создание резервной копии в PowerShell:
```powershell
Copy-Item data\database.db "data\database_backup_$(Get-Date -Format 'yyyyMMdd_HHmmss').db"
```

Для восстановления достаточно переименовать файл резервной копии обратно в `database.db`.
